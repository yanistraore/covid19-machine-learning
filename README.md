# Projet COVID-19 : prédiction du diagnostic par machine learning

Projet final d'une formation en Machine Learning suivie sur la chaîne YouTube [MachineLearnia](https://www.youtube.com/@MachineLearnia)

Le notebook `Untitled10 (1).ipynb` contient :
- mon travail d'exploration des données (EDA) 
- le code de la formation pour le prétraitement, la modélisation et l'évaluation (notebooks 27 à 29 et bonus), adapté au jeu de données `projetfinal.ml.xlsx`

Les données décrivent des patients testés pour le SARS-CoV-2, avec leurs résultats sanguins et viraux, provenant de l'Albert Einstein Hospital


Pour exécuter le notebook, place `projetfinal.ml.xlsx` dans le même dossier
